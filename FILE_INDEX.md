# Project File Index

- `index.html` — expense entry form, spending summary, category breakdown, and transaction list
- `styles.css` — responsive visual design and accessibility focus states
- `script.js` — expense management, monthly calculations, search, filters, and persistence
- `README.md` — project overview and complete usage guide
- `QUICK_START.md` — short getting-started guide
- `TECHNICAL_DOCUMENTATION.md` — data model and implementation notes

Open `index.html` in a modern browser to use the tracker. No dependencies or build step are needed.
